Various utilities

Shattering behavior

The item breaks into pieces when it cools too quickly.

Can be added to the item or the block:


{
	"behaviors": [
		{
			"name": "glassmaking:shatterable",
			"properties": {
				"glass": {
					"GLASS_CODE": GLASS_AMOUNT
				},
				"drops": [
					{
						"code": ...,
						"type": ...,
						"quantity": ...
					}
				]
			}
		}
	],
}
  • glass - a list of the glass mass contained in the item that will drop as shards.
  • drops - a list of generic items that will drop in addition to glass shards. (Optional)
